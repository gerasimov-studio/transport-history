# История транспорта

Публичная карта читает снимки из PostGIS. Наполнение — отдельная студия, на главной странице входа нет.

Система проектируется как единая мировая транспортная карта. Города не являются контейнерами
сети: публичная карта запрашивает объекты по видимой области, масштабу и дате. Существующий
`city_id` пока сохраняется как совместимость старого редактора и источник начальной позиции карты.

Пространственная проекция `network_infra` / `network_routes` автоматически строится из журнала
событий. Публичный эндпоинт `/api/map?bbox=west,south,east,north&date=YYYY-MM-DD&zoom=N`
использует индекс PostGIS и не восстанавливает всю сеть при каждом перемещении карты.

Студия загружает то же окно карты с полной детализацией и сохраняет изменения через
`/api/objects/commit`. Запрос содержит только изменённые объекты и явные удаления, поэтому
перемещение по мировой карте не затрагивает данные за пределами открытой области.

Редактор сохраняет изменения как `changeset` в рабочем пространстве. Для основной карты
действует процесс `draft → submitted → published`: черновик не виден на публичной карте,
пока модератор его не опубликует. Таблицы `moderation_areas` и `moderation_assignments`
задают пространственные зоны ответственности. Пользовательские сценарии создаются как
отдельные пространства типа `scenario` с основной картой в качестве основы.

На выбранную дату для каждого включённого вида берётся последний снимок с датой `<=` текущей.

## Запуск

Через Docker на `https://th.test` (сеть `proxy` и Traefik из `_local-infra`):

```bash
docker compose up --build -d
```

Карта: `https://th.test`  
Студия (не ссылается с карты): `https://th.test/edit`  
Локальный вход: `editor` / `editor` (см. `EDITOR_USERNAME` и `EDITOR_PASSWORD`).

Локально фронт с прокси на API:

```bash
docker compose up --build -d db api
npm install
npm run api
npm run dev
```
