# Контекст проекта

Документы в этой папке дают разным чатам общий, версионируемый контекст.

1. Каждый чат начинает с корневого `AGENTS.md`.
2. Общая модель продукта и системы находится в `PROJECT_CONTEXT.md`.
3. Рабочие границы конкретного направления находятся в `domains/`.
4. Детальное техническое устройство описано в `../ARCHITECTURE.md`.

Рекомендуемая стартовая формулировка для нового чата:

> Работай над доменом «редактор». Сначала прочитай `AGENTS.md`,
> `docs/PROJECT_CONTEXT.md`, `docs/domains/editor.md` и `ARCHITECTURE.md`.
> Не изменяй транспортные данные без отдельного явного запроса.

Эти документы описывают устойчивые решения и текущее состояние, но не служат
бэклогом. Конкретная задача и критерии готовности задаются в соответствующем
чате.
