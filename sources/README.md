# Исходники снимков сети

Сюда кладём GIF из архива. Приложение их не показывает: по файлу чертится GeoJSON.

Имя: `{Город}_{КОД}_{YYYY}_{MM}_{DD}.gif`

Коды: `ЖД` железная дорога, `ТМ` трамвай, `МТ` метро, `ТБ` троллейбус,
`АВ` автобус.

Пример: `Нарын_ТБ_1994_12_30.png` → `sources/naryn/trolleybus/1994-12-30.png`
